## ✧ About NEXORA

NEXORA is a personal website project built around creativity, visual expression and digital design.

The idea was to take a slideshow-style website and make it my own by changing its content, experimenting with colours, exploring different visuals and adding personal touches.

It's not about being perfect — it's about trying things, learning and creating something different.

## ◈ What's Inside?

- **Creative Slideshow** — Explore different sections through an interactive presentation.
- **Visual Gallery** — A collection of images and visual inspiration.
- **Bold Design** — Bright colours, oversized typography and a distinctive style.
- **Animations** — Interactive elements and smooth transitions.
- **Personal Touches** — Customised text, content and details throughout the website.

## ✧ What I Changed

The project started with an existing slideshow website template, which I used as a foundation for my own customisation.

Some of the changes I made include:

- Changed the original website name and branding to NEXORA.
- Reworked the original text and descriptions.
- Updated the gallery images and visual content.
- Customised the contact section and other page content.
- Experimented with colours, typography and design details.

## ◈ How to Run the Project

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html`.
4. Run it in your browser, or use the Live Server extension.
